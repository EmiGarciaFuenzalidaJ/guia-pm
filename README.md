# Guía de Project Management 2026

Guía abierta y gratuita de Project Management en español, actualizada a noviembre de 2026.

9 módulos: fundamentos, iniciación, planificación, ejecución, agile, IA y agentes, skills transversales, stack del PM y tendencias 2026. Alineada con PMBOK 8 y el nuevo examen PMP.

Es un único archivo `index.html` (HTML + CSS + JS, sin dependencias de build), pensado para leerse también en el celular.
